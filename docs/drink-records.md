# 饮水记录

本分支基于 `main`，独立提供 `/setting/history/` 页面，不依赖统计或主题分支。

- 手动记录 50/100/200/300 ml；失败后保留请求 ID 和原水量用于重试。
- 全屏提醒共用后端会话，多屏同时确认只记录一次。点击时获取当前会话，延迟关闭只作用于原会话。
- 后端串行执行读取、去重、写入和撤销；兼容旧版数字总量。保存报错恢复内存，重试不重复累加。
- 明细按近 7/30 天展示；带请求 ID 的记录支持二次确认后撤销。旧版总量及无 ID 明细只读。
- 撤销保留历史目标和去重墓碑，重复撤销不重复扣减，原请求不能重新添加已撤销记录。
- 提醒超时由后端关闭并释放 Esc。成功记水即确认会话，关闭动画期间超时仍按确认处理。

`reminder_session.rs` 仅提供通用会话生命周期和结束事件，供可选统计功能观察；本分支不写入提醒统计、绘制图表或切换主题。

## 验证

```sh
corepack yarn install --frozen-lockfile
node --test tests/*.test.cjs
corepack yarn eslint -c src/eslint.config.mjs src
corepack yarn build
cargo test --workspace --locked
```

Rust 测试覆盖并发累加、会话去重、跨日重试、旧总量升级、失败恢复、撤销墓碑以及过期关闭请求。前端测试覆盖兼容读取及 IPC 参数。

浏览器以模拟 Tauri IPC 验证手动记录、失败重试、二次确认撤销、即时获取提醒会话；原生多屏和 Windows/Linux 桌面交互仍需实机验收。

这里的原子性指应用进程内串行更新与去重。底层 Store 使用普通文件写入，不保证断电或磁盘写入中断时的事务性恢复。本分支不提供数据导入。
